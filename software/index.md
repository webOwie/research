# Research Software

This index documents software outputs that support or result from webOwie research activity.

## Current status

Active development projects are listed under the project index. A project moves into this software index when a public source repository, release or stable version record exists.

## Minimum metadata for future entries

- software name and purpose
- repository URL
- version or release identifier
- release date
- supported environment
- license
- related research project
- reproducibility or installation notes
- citation metadata where appropriate
