# Research & Development Projects

This directory indexes active webOwie research and development work.

A project record is **not** a publication record. Entries here describe purpose, scope and current development status. Completed outputs should be indexed separately under publications, software, datasets, methods or research notes when a persistent source record exists.

## Status vocabulary

- **Active R&D** — currently being designed, implemented or tested.
- **Experimental** — exploratory implementation without a stable release commitment.
- **Published output** — an output with a real public source record, version or persistent identifier.
- **Archived** — retained for reference but no longer active.
