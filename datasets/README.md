# Datasets

This index is reserved for datasets that are appropriate for public research use and have documented provenance, scope and licensing.

## Current status

No dataset is indexed here yet.

## Minimum metadata for future entries

- dataset title
- description and research purpose
- creator or maintainer
- creation and update dates
- source provenance
- collection methodology
- coverage and known limitations
- file formats and schema
- privacy and ethical considerations where relevant
- license
- persistent identifier or stable download URL
- checksum or version information where appropriate

Datasets must not be listed as public outputs until their source, rights and publication status are clear.
