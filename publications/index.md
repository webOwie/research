# Publications

## Minimum metadata for future entries

- title
- author or authors
- publication date and type
- abstract or concise summary
- persistent identifier such as DOI or Zenodo record
- canonical source URL
- ORCID attribution
- version and license
- related repository or dataset
- recommended citation
