# Publications

This index is reserved for published research outputs with verifiable source records.

## Current status

No publication record is indexed here yet.

That is deliberate. Drafts, planned papers and active projects are not presented as publications until a real public record exists.

## Minimum metadata for future entries

Each publication entry should include, where applicable:

- title
- author or authors
- publication date
- publication type
- abstract or concise summary
- persistent identifier such as DOI or Zenodo record
- canonical source URL
- ORCID attribution
- version
- license
- related repository or dataset
- recommended citation

Technical reports without a DOI may still be indexed when a stable public source and version are available.
