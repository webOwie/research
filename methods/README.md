# Methods

This index documents reproducible technical and research methods used across webOwie Research.

## Current status

No formal method record is indexed here yet.

## Minimum metadata for future entries

- method name and objective
- applicable research area
- prerequisites and assumptions
- input data or system requirements
- step-by-step procedure
- validation or verification procedure
- expected outputs
- limitations and failure modes
- software and version dependencies
- ethical, legal or privacy constraints where relevant
- related project, publication or dataset

A method should be detailed enough for an independent reader to understand what was done and reproduce the procedure where access and legal conditions permit.
